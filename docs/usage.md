# 使用说明

本文说明账号、模型、任务和手机运行行为。安装与构建步骤见[项目首页](../README.md)。

## 账号、模型与任务


- “我的”保留开源许可、赞助、免责声明、联系我们，并增加 AI 模型入口；底部为学习、记录和我的。
- 点击头像打开账号抽屉，通过“连接其他账号”输入学习通账号密码。验证成功后保存；平台要求验证码或安全验证时会显示错误提示。
- 登录后自动读取平台真实姓名，不用手填备注代替姓名；若平台暂未返回姓名，明确显示“姓名未获取”。“检查连接”也会更新姓名。
- 第一个账号自动成为默认账号；添加其他账号不会改变默认选择。在抽屉中点选账号即可切换，默认选择重启后仍保留。账号列表最高为 240px 且不超过屏幕高度的 32%，更多账号在列表内部滚动，下方操作固定可见；打开时自动定位选中的账号。
- “检查连接”会重新登录并读取课程。网络或验证失败会显示错误，并将连接状态改为待检查。
- 重复添加同一账号会更新平台姓名和密码，不增加重复记录。移除默认账号后使用列表中首个剩余账号，移除最后一个则清空默认值。
- AI 模型支持多配置、编辑、删除、主模型和可选备用模型。填写接口与 Key 后点击“连接测试”自动获取模型，主模型与备用模型支持搜索选择。编辑时 Key 留空沿用已保存密钥；更换接口地址必须重新输入 Key。
- 支持 Chat Completions、Responses、Anthropic Messages 三种格式，分别适配路径、认证、请求体和响应解析。填写服务商基础地址或完整接口地址，保留 `/openai/v1` 等前缀。“测试主模型”发送简短消息验证实际调用，可能消耗少量额度；单纯获取列表不代表模型或额度可用。完整配置可先保存，测试失败会显示经过脱敏的服务端原因；402 单独提示额度已达上限。
- 课程列表在新建任务中按所选账号读取；学习首页恢复概览、任务卡片和记录入口。
- 首页“新建任务”按账号与课程、AI 模型、运行设置三个步骤填写。账号和模型配置均为底部抽屉单选，列表较长时支持搜索和内部滚动，直接使用“我的”中已保存的资料，不重复填写密码和 API Key。
- 三步指示器等分排列，圆点和连接线居中对齐。下一步保持可点击；缺项时停留当前步骤，滚动并聚焦首个错误字段，显示红框与具体说明，补齐后自动清除。保存时重新校验全部步骤和运行参数。
- 新任务预选当前默认账号；任务中切换账号会清空已选课程并重新获取对应课程，不改变全局默认账号。课程支持多选或手动输入 ID。
- 任务选择一个完整的 AI 配置，沿用其接口、Key、主模型和备用模型；可从表单进入配置管理再返回，保留当前填写内容。
- 任务配置加密保存于本机，支持编辑、删除和重启后恢复。已有任务保留原账号及模型引用；移除所引用的配置后显示“配置待修复”，不会自动更换身份。
- 学习首页使用适度收矮并保留宽松留白的任务卡片，直接显示课程名称。长按卡片约半秒打开编辑、删除菜单，滑动或松手会取消长按；电脑端支持右键和键盘 Enter / Shift+F10。删除前仍需确认。手填 ID 的课程如果尚无名称，会显示“课程名称待获取”；编辑任务重新读取课程后补全名称。
- 卡片保留适度留白，最新进度用一行小字显示，播放时段固定在右侧；当前课程名称随进度更新。页面可见时每 2 秒读取一次最新状态，离开页面或切到后台后停止刷新，不在卡片堆积历史日志。

账号和模型配置经 AES-GCM 加密保存在 `data/settings.enc`，密钥为 `data/vault.key`。两者需一起备份，请勿提交到公开仓库。API 不返回密码和模型密钥明文。服务仅监听本机地址；端口通过 `TIANTIAN_PORT` 修改，开发代理默认连接 18081。

`GET /api/task-defaults` 返回默认账号 ID；任务创建、编辑、列表、删除分别使用 `POST /api/tasks`、`PUT /api/tasks/{id}`、`GET /api/tasks`、`DELETE /api/tasks/{id}`。任务仅保存账号及模型配置 ID 和运行参数，不复制凭据。保存后点击卡片启动，在 Android 本地执行；同一时间运行一个任务，章节可按设置并发。运行中的任务先停止再编辑或删除。电脑预览不启动手机执行器。

最新进度接口为 `GET /api/task-progress`，卡片仅保留最新状态；`GET /api/records` 返回最近 500 条执行记录。二者在本机服务重启后清空。原生执行接口需要不暴露给网页的随机令牌及每次运行独立的运行 ID，解密后的凭据只传给进程内执行器。停止同时取消章节调度、等待和后续请求，已发出的网络请求可能需等待超时。执行器按平台状态核验完成，未完成、未开放和验证失败不会标记为全部完成。AI 认证或 402 额度错误会停止任务。

手机运行设置提供通知设置和电池优化入口，状态读取自 Android。启动后显示常驻通知与停止入口，使用前台服务和有时限的唤醒锁。系统强行停止或设备重启后，需要重新点击启动，从平台已保存进度继续；Android 对数据同步前台服务的运行时长和后台限制仍然生效。
